# Km Capture V2

Android app that photographs fuel slips (or takes them from the gallery), reads the details, and exports them to Excel by vehicle and date.

## Build the APK online

1. Push this project to GitHub (branch `main`).
2. Open the **Actions** tab, choose **Build APK**, and click **Run workflow** (it also runs on every push).
3. When the run finishes, open it and download **KmCapture-V2-apk** under *Artifacts*. Unzip it to get `app-debug.apk`.
